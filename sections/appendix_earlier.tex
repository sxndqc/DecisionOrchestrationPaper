\section{Earlier experiments: fragment decisions by Claude Sonnet 5.5}
\label{app:sonnet}

Before the experiments of the main text, we ran the fragment-mode \umr procedure with a stronger parser, Claude Sonnet 5.5, on Chinese \umr, with an earlier hand-written seed that contained worked examples, an earlier test protocol (whole documents; AnCast++ instead of the shared task's metric) and unmeasured reflection by Claude Opus 5.5 on one whole training document per round. These numbers are not comparable with the main text (different seed, test documents, metric and gold exposure) and are reported for completeness.

One training document raised the first test set from 45.3 to 50.8 \F and a second to 52.6, with temporal relations improving most; third and fourth documents left the test scores flat. Unmeasured reflection accepted 440 of 441 edits and the skills grew from 41k to 156k characters in ten rounds, which motivated the length compression of the main text.
